ABOUT

À propos de ChurnGuard

Une interface web séparée du modèle pour une architecture plus réaliste.

Architecture

FrontendHTML / CSS / JavaScript
→
APIFlask / Python
→
MLScikit-learn / Joblib

Objectif

Transformer un notebook de Machine Learning en une application exploitable par un utilisateur non technique, tout en conservant le pipeline d'entraînement et le seuil optimisé.

Limites

Le score est une estimation statistique. Une probabilité élevée ne signifie pas qu'un client quittera nécessairement l'entreprise. L'application est un outil d'aide à la décision.
